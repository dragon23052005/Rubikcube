Tips for printing

For the best results, I advice you to do the following steps:

  • Download the Opera browser and install it on your PC.
  • Run Opera and browse to the printable page.
  • Go to the File menu and select Print setup.... Set the Orientation to Landscape and confirm your choice by pressing the OK button.
  • Go to the File menu and select Print options.... Set the Scale print to value to 50% and confirm your choice by pressing the OK button.
  • Go to the File menu and select Print preview. Normally, the page should fit exactly on 2 sheets of paper. If it doesn't seem to fit, go to the File menu, select Print options... and adjust the Page margins until you're statisfied.
  • Print out the page by pressing CTRL+P or by using the File menu.

Doing it this way, it should come out pretty well but of course results may vary depending on the type of printer you use.
